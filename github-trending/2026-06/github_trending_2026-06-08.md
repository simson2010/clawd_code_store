# Github Daily Trending - 2026-06-08

## 趋势分析

今日Trending主题聚焦于**AI Agent工具与技能生态**：

1. **AI Agent技能爆发** - 多个项目专注于增强AI代理能力，包括研究技能(last30days-skill)、设计品味技能(taste-skill)、自演进代理(hermes-agent)和可扩展代理(goose)
2. **开源替代方案** - 开源实现专有工具的需求旺盛，如open-notebook作为NotebookLM的开源替代，支持本地部署和多模型
3. **反"Slop"设计** - taste-skill明确提出"反Slop"理念，提升AI生成代码的设计质量
4. **跨平台代理** - 强调多平台支持(Telegram、Discord、Slack等)和多种部署方式(本地、云服务器、无服务器)
5. **隐私优先** - 本地AI工具受关注，数据控制在本地，支持18+AI提供商
