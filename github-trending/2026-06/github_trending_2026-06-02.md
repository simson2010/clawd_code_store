1. **AI Agent/WebUI工具爆发** - 多个项目专注 于增强AI Agent的易用性，包括Hermes WebUI（网页端访问）、Supermemory（记忆引擎）、impeccable（设计语言）等，反映出AI助手正从CLI向更友好的Web界面迁移。

5. **编程教育与自研** - build-your-own-x持续热门，鼓励开发者从零实现核心技术。
