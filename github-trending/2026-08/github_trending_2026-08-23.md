# Github Daily Trending - 2026-08-23

## 趋势分析
今日GitHub Trending呈现以下主要趋势：

1. **AI Coding Agent井喷式爆发**：前四位全部是AI编码代理工具（Codex、skills、ECC、superpowers），说明开发者对本地运行的AI编程助手需求强烈。OpenAI的Codex和Anthropic的Claude Code形成直接竞争态势。

2. **Agent技能框架成为热点**：mattpocock/skills、obra/superpowers等围绕"技能(Skills)"的项目大火，反映出开发者希望在AI代理中获得更多控制权，而非完全"自动驾驶"。

3. **开源项目管理和工作流自动化**：Plane（开源Jira替代品）和n8n（工作流自动化）持续热门，说明开发者对自托管工具的热情不减。

4. **开发者工具本地化/开源替代品**：OpenLogi（Logitech Options+开源替代）体现对本地、无遥测软件的偏好。

5. **AI基础设施安全**：Tencent的AI-Infra-Guard专注于AI系统的红队安全评估，反映AI安全日益重要。
