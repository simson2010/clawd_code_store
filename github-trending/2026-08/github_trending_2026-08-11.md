1. **AI Agent 基础设施持续火热**：多个项目聚焦于AI Agent的编排、管理和自我改进能力。Semantica提供图结构基础设施解决AI决策的可追溯性问题；Paperclip定位为AI员工的"公司"管理系统；Prime Agent主打自改进RLM Agent；Agent Skills提供生产级工程技能。
