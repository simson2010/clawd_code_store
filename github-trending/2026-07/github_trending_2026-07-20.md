# Github Daily Trending - 2026-07-20

## 趋势分析

今日GitHub Trending呈现以下主题趋势：

1. **AI开发工具与MCP (Model Context Protocol)** - 多个项目围绕MCP展开，包括code-review-graph（代码智能图谱）、wigolo（MCP搜索工具）、AstrBot等，MCP生态正在快速扩张

2. **本地AI应用** - voicebox（AI语音工作室）、AirLLM（单卡推理）等项目强调本地运行，保护隐私

3. **LLM推理优化** - ktransformers继续热门，支持多种大模型的CPU-GPU异构推理优化

4. **开发者效率工具** - PostHog（产品分析）、jellium-desktop（Jellyfin桌面客户端）、microsoft/terminal等工具类项目保持热度

5. **编码代理 (Coding Agents)** - jcode、cua、kimi-cli等项目持续推动AI编程自动化
