# Github Daily Trending - 2026-09-18

## 趋势分析

今日GitHub Trending呈现以下核心趋势：

1. **AI Coding Agent 工具爆发**：多个项目聚焦于提升AI编码助手的能力，包括代码审查、安全审计、Browser自动化等。alibaba/open-code-review、cloudflare/security-audit-skill、addyosmani/agent-skills 等项目都是这一趋势的代表。

2. **Browser自动化成为热点**：Tencent发布的BrowserSkill让AI代理可以使用用户已登录的浏览器，这是一个重大突破，解决了AI代理无法访问需要登录的Web服务的问题。

3. **AI研究助手兴起**：OpenResearch将编码代理转变为研究代理，支持文献综述、假设开发、实验运行等完整研究流程。

4. **企业级应用增长**：Ghidra（NSA逆向工程框架）、Cilium（eBPF网络）、n8n（工作流自动化）等企业级项目持续热门。

5. **语音/多媒体AI**：voicebox作为开源AI语音工作室，提供克隆、听写、创作等功能。
