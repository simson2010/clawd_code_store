# Screen Spec 模板

> **用法**：每个 Flutter 屏幕一份，由 Analyzer Agent 填写。
> **硬规则**：
> 1. 每一节必填；无内容写 `N/A` 并说明原因，**不允许留空**
> 2. 禁止出现 Dart 语法、Dart 类型名、widget 名 —— 只描述行为与数据
> 3. 状态机与并发两节是最高频遗漏项，必须逐条枚举
> 4. 本文件是 Implementer Agent 的**唯一输入**，它不得读取 Dart 源码

## 10. 埋点

> 埋点方案已由 Tagging 文档统一定义，事件名必须从生成的 Swift 枚举取，**不得写字面量**。

### 10.2 曝光埋点（Redux 无法覆盖，必须单列）

> 「元素露出 X% 持续 N 秒 = 曝光」是 View 层可见性判定，Reducer 看不到。
