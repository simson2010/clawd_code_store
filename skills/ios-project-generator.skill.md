# SKILL install 

## ios-project-generator.skill

### download ios-project-generator.skill
Location: https://github.com/simson2010/clawd_code_store/blob/main/skills/ios-project-generator.skill
```bash
$> curl https://github.com/simson2010/clawd_code_store/blob/main/skills/ios-project-generator.skill -o ~/Downloads/ios-project-generator.skill
```

### unzip 
Unzip ios-project-generator.skill to `your` `skills` folder if you're a Code Agent like `opencode`, `claudecode` etc.

```bash
$> unzip ~/Downloads/ios-project-generator.skill ~/your/path/to/coding_agent/skills
```
